## Preflight rulings

- Ruling: new governance rules (REQ008–REQ015) activate only through configuration; embedded defaults keep exactly the legacy four rules so the frozen Aegis v1 contract (`legacy_projection` equality) is never broken — if wrong, a config-free consumer would see new findings appear after upgrade.
- Ruling: the query engine's relation clauses use a semantic inverse view built from `(semantic_family, swapped roles)`; families without an inverse entry match nothing when inverted — if wrong, `references`-style relations would need synthetic inverse names that no catalog entry defines.
- Ruling: Lua receives materialized ID sets and a precomputed report under `extensions.quartoNeeds`; it never evaluates ASTs or recomputes coverage — if wrong, Python/Lua evaluator drift becomes possible and violates the spec's single-reference-evaluator rule.
- Ruling: wall-clock time enters results only through `config.reference_date()` (prefers `SOURCE_DATE_EPOCH`, else today) and every finding/report carries its reference date — if wrong, expiry findings would be irreproducible day-to-day.
