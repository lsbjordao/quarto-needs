6  Implementation: tracing architecture into the repository

Architecture components describe logical responsibility. Source modules show where that responsibility is actually implemented. Keeping those layers separate prevents a common traceability mistake: treating a Python or JavaScript file as if it were an architectural component.

The source-module objects below point to real files in this repository. Their implements relations connect code back to approved engineering obligations while the existing implemented-by relations continue to connect requirements to logical components and interfaces.
