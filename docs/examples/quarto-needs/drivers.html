3  Drivers: why Quarto-Needs exists

Requirements engineering starts before system requirements. The first layer records the concerns that justify the product; the second translates them into obligations for the system.

SYS-009 · Deliver the semantic engine through the activated extension itself

system-requirement approved high

Quarto-Needs shall provision and invoke an exact, compatible semantic engine from the activated extension during ordinary rendering, without a global package installation, a CLI on PATH, or a user-authored pre-render.

distribution extension installation provisioning

Rationale

One installation responsibility keeps adoption honest: the extension a user adds is the component that works, and its engine cannot silently drift from it.
